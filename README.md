Finance Loan Analytics Dashboard 

This interactive Excel dashboard analyzes loan data to provide clear insights into loan performance. It tracks key metrics like application volume, funded and received amounts, interest rates, and borrower health using pivot tables, slicers, and charts.

🔧 Data Preparation & Cleaning
• Cleaned raw loan data by fixing missing values, removing duplicates, and standardizing formats
• Organized the data for easy analysis with pivot tables
• Selected key columns like loan type, status, debt-to-income ratio, and issue date for KPI tracking

🔍 Key Features
• Total Loan Applications (Month-to-Date and Month-over-Month)
• Funded and Received Amounts
• Breakdown of Good vs. Bad Loans
• Approval and Rejection Trends
• Average Interest Rates and DTI Ratios
• Analysis by Region, Loan Term, and Loan Purpose
