🏦 # Finance Loan Analytics Dashboard 

This interactive Excel dashboard analyzes loan data to provide clear insights into loan performance. It tracks key metrics like application volume, funded and received amounts, interest rates, and borrower health using pivot tables, slicers, and charts.

🔧 Data Preparation & Cleaning
• Cleaned raw loan data by fixing missing values, removing duplicates, and standardizing formats
• Organized the data for easy analysis with pivot tables
• Selected key columns like loan type, status, debt-to-income ratio, and issue date for KPI tracking

🔍 Key Features
• Total Loan Applications (Month-to-Date and Month-over-Month)
• Funded and Received Amounts
• Breakdown of Good vs. Bad Loans
• Approval and Rejection Trends
• Average Interest Rates and DTI Ratios
• Analysis by Region, Loan Term, and Loan Purpose

• Financial_Loan.xlsx – The interactive dashboard file
• Screenshots – Visual previews of charts and KPIs

📌 Problem Statement
The goal of this project is to build a comprehensive Finance Loan Report Dashboard using Excel to monitor and analyze loan applications and disbursements. This dashboard is designed to support financial institutions in making data-driven decisions by offering real-time visibility into loan performance metrics.

🟢 Dashboard 1: Summary KPIs
1. Total Loan Applications
• Track total number of loan applications within a selected period
• Monitor Month-to-Date (MTD) applications and Month-over-Month (MoM) changes

2. Total Funded Amount
• Calculate the total amount disbursed as loans
• Analyze MTD funded amounts and observe MoM fluctuations

3. Total Amount Received
• Monitor repayments received from borrowers to evaluate cash flow
• Evaluate MTD received amounts and repayment trends

4. Average Interest Rate
• Calculate the average interest rate across all loans
• Monitor changes in average interest rates MoM to gauge loan cost patterns

5. Average Debt-to-Income (DTI) Ratio
• Analyze average DTI across all loans
• Useful for assessing borrower financial health

🟢 Good Loan vs Bad Loan KPIs
Good Loan KPIs:
• Good Loan Application Percentage
• Good Loan Applications
• Good Loan Funded Amount
• Good Loan Total Received Amount

Bad Loan KPIs:
• Bad Loan Application Percentage
• Bad Loan Applications
• Bad Loan Funded Amount
• Bad Loan Total Received Amount

Loan Status Grid View:
A structured grid view categorizes loan metrics by loan status, helping the team monitor approval/rejection rates, funded vs received amounts, average interest rates, and average DTI values for better portfolio health management.

🟢 Dashboard 2: Overview (Charts & Visual Insights)
1. Monthly Trends by Issue Date (Line Chart):
Shows seasonal and long-term lending trends.

2. Regional Analysis by State (Filled Map):
Reveals geographic differences in lending volume and performance.

3. Loan Term Analysis (Donut Chart):
Illustrates distribution of loans by term duration.

4. Employee Length Analysis (Bar Chart):
Assesses borrower employment length vs. loan metrics.

5. Loan Purpose Breakdown (Bar Chart):
Highlights loan volumes by stated borrowing purpose.

6. Home Ownership Analysis (Tree Map):
Shows how homeownership status correlates with loan disbursement trends.

Displayed Metrics:
• Total Loan Applications
• Total Funded Amount
• Total Amount Received

🟢 Dashboard 3: Details
Purpose:
A user-friendly and consolidated Details Dashboard that provides a snapshot of all essential loan metrics in one place.

Objective:
To offer a single-window interface for accessing vital loan data, enabling users to evaluate borrower profiles, loan types, risk exposure, and overall loan performance effectively.
